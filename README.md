### Über dieses Repository

Dieses Repository enthält die **Link-in-Bio-Seite des freezeclub Balingen**, gehostet über
GitHub Pages unter **https://links.freezeclub.de/**. Reines HTML/CSS/JS, self-contained in
`index.html`, Bilder in `assets/`.

- **Layout:** mobile-first einspaltig; ab 960 px zweispaltig (`.shell` → `.colA` sticky
  Brand/Angebot links, `.colB` Content rechts), die mobile Sticky-Bar wird dann ausgeblendet.
- **Aufbau:** Logo-Header → Aktions-Hero + Deal-Liste + Kältekammer- und Probemonat-Streifen → Foto-Slider →
  Anwendungen → Termin & Kontakt → Über uns → Bestandskunden (RemediCool, Shop) → Podcast/Shop/
  Website → Socials → Footer.
- **Bilder:** Slider nutzt `gallery-kaeltekammer.jpg`, `anwendung-lymphdrainage.jpg`,
  `anwendung-bodyscan.jpg`, `gallery-theke.jpg`. Team = Jana & Marc (Porträts in `assets/`) +
  Steven; die Team-Slide ist aktuell nicht eingebunden.
- **Share-Preview:** `assets/og-image.jpg` (1200×630), `og-image.png` bleibt als Fallback für
  gecachte Vorschauen liegen.
- **Angebote pflegen:** Hero, Streifen und Sticky-Bar verlinken auf Shop-Produkte – vor dem
  Wechsel einer Aktion prüfen, ob der Produktlink noch existiert. Der Probemonat im Streifen ist
  eine WhatsApp-Anfrage, kein Shop-Produkt. Bei Preis- oder Aktionswechsel auch `llms.txt` anpassen.
- **Aktions-Ablauf:** Elemente mit `data-deal` (Hero, Deal-Liste) blenden sich nach dem Enddatum
  im Script (`END`) automatisch aus; Sticky-Bar und Streifen springen dann auf das
  Kältekammer-Kennenlern-Angebot. Neue Aktion = Inhalte, Preise und `END` anpassen.
- **Aktionsmonat Deal Weeks (Plan laut Asana „freezeclub“):** W1 13.–19.10. Lymphdrainage −25 % ·
  W2 20.–26.10. 10er Karte 179 € · W3 27.10.–02.11. Kältekammer −25 % · W4 03.–09.11. Big Pack
  40 Anwendungen 399 €. Start jeweils 0 Uhr, Ende 23:59 Uhr; Shop-Preise mit Vergleichspreis.
- **Tracking:** Shop-Links tragen `utm_source=linkinbio&utm_medium=social&utm_campaign=…` –
  Käufe über die Link-Seite sind so in Shopify-Analytics auswertbar.
- **GEO/SEO:** `llms.txt` fasst Studio, Anwendungen, Angebote und FAQ für KI-Suchsysteme zusammen;
  `robots.txt` erlaubt alle Crawler (auch GPTBot, ClaudeBot, PerplexityBot u. a.) und verweist auf
  `sitemap.xml`.
